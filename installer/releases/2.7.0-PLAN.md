## How to work (read first)
- Source: `desktop_watch/` (server.py, cleaner.py, updates.py, tray.py, window.py, static/app.js · i18n.js · app.css · index.html).
  `APP_VERSION` is still '2.6.0' — set '2.7.0' with the first change.
- Tests: `tests-local/` (not in git). Full run: `cmd /c "tests-local\admin_run.cmd"` → `tests-local\admin-results.txt`
  (22 "ALL PASSED" suite lines + 199 PASS lines = 294 checks on 2.6.0). Standard user: `runas /trustlevel:0x20000 "cmd /c …\nonadmin_run.cmd"`.
  Each suite starts its own instance with `--data <scratch> --port <n> --no-tray --no-browser`; never the owner's real instance.
  Add one `t_*.py` per feature and append it to both .cmd lists.
- Screenshots: `tests-local\shots260.py` (headless Edge + CDP) → Desktop `桌迹<version>截图`.
- Pitfalls: Git-Bash heredocs mangle backslashes → write patch scripts with the Write tool; console is GBK → never redirect Python
  stdout into UTF-8 files; i18n lives in layered `Object.assign(I18N.xx, {...})` blocks appended before `let LANG`; UI strings need en + zh.
- Release: `installer/releases/2.7.0.json` → `python installer/add_release.py …` → license in `dist/licenses`, copy to Desktop
  `DeskTrace updates`; `python installer/build_installer.py`; Gemini brief in Chinese on the Desktop; owner tries it; then GitHub
  (memory: desktrace-github). Tag removed/replaced features in changelog.json (memory: net-update-notes).

## P0-0 pre-check (done 2026-11-10)
- `scan_history(drive, serial, finished, sizes)`: sizes of folders ≥ 50 MB per **full** scan, last **30 scans** per drive. Background
  pre-scan is every 12 h → about 15 days of depth. S1.1 (30/14/7-day playback) therefore needs: keep one scan per day for 90 days
  (thin older ones) — to do with S1.1.
- Snapshots: new versions SHA-256 (64 hex), versions kept before 2.4.2 SHA-1 (40 hex), both readable; files `blobs/<2 hex>/<hash>`,
  DTS1 (zlib) or raw. UI wording must say "SHA-256" / "SHA-1" as it really is (M2-21, S3.1).
