- adaptive full rescans: with instant detection healthy, full rescan far less often (e.g. 10 min) — L4
- background process mode (PROCESS_MODE_BACKGROUND_BEGIN) for the service: low CPU + I/O + memory priority — L3
- window: pause timers / polling while hidden or minimized (stats 30s, times 15s, badges 2min) — L3
- SQLite indexes for events(path), events(old_path), events(ts), events(kind,ts); PRAGMA optimize in housekeeping — L3
- cache duplicates/space/writing by a change generation counter (no recompute when nothing changed) — L3
- writing(): computed progress twice per document — compute once — L2
- large-file duplicate hashing: throttle (pause between blocks, stop when user busy) — L3
- startup: defer badge loads (dups/space/writing/rules) a few seconds after first paint — L2
- caps: diff_cache / current_cache by total size, not count — L2

## Major new feature (L5): Folder time travel
Restore a whole folder as it was at any moment into a NEW folder ("<name> (as of <date time>)"), never overwriting;
report files that could not be rebuilt (no snapshot). Entry points: Space folder view / Files / folder context, pick date+time.
Per path: first event after T → its prev version (created after T → absent); none after T → current file.
Follow renames.
